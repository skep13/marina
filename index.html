Marina

An anime character who sits on my Mac desktop and talks back.

Source on GitHub · built on riko_project

This is the same renderer the app uses, running in your browser. Here she only has a few pre-recorded lines, because the real app needs a language model and runs the voice on your own machine. Type something, hover over her, or leave the page alone for a bit and she'll talk first.

What the app does

On the desktop she lives in a transparent window that stays on top of everything else. You can talk to her or type, and she answers out loud, lip syncs, and acts out anything the model writes in asterisks, like *rolls her eyes*, instead of reading it out.

Speech recognition (Faster-Whisper) and her voice (Kokoro) run locally. The language model can be anything with an OpenAI-compatible API, so Ollama on the same machine works fine. I run it on a MacBook Air with 8 GB of RAM.

She starts talking as soon as the first sentence is ready, you can cut her off by talking over her, and if it's been quiet for a while she'll sometimes start the conversation herself. She also remembers things about you between conversations.

Running it

Clone the repo into ~/marina on a Mac, then:

./setup-mac.sh
cp character_config.example.yaml character_config.yaml
./build-app.sh

Before building, set your model endpoint in character_config.yaml and put a .vrm file at app/models/model.vrm. That puts Marina.app in Applications. The README has the rest.
